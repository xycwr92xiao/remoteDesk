昕宇局域网远程工具，支持winddows、linux(UOS、银河麒麟;x86_64、arm及loongarch架构)
在windows10、11及UOS和银河麒麟两种linux x86_64、arm及loongarch三种架构等环境测试通过有苹果电脑及其它环境的可自行编译测试。
支持共享剪切板、单一文件的复制粘贴、文件传输功能。
